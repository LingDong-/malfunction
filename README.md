# [MALFUNCTION](https://malfunction.netlify.app/)

New web experiments (2025-) by Lingdong Huang.

Previous projects (2018-2025) have been archived at [UNGLITCH](https://unglitch.netlify.app/).

This repository hosts both the source code for the projects, as well as that of an [IDE for editing them online](https://malfunction.netlify.app/editor/). To explore a project, check out the corresponding top-level folder. ([e.g.](face-term/))

To reuse the IDE for your own projects, see [https://malfunction.netlify.app/editor/?action=help](https://malfunction.netlify.app/editor/?action=help).
